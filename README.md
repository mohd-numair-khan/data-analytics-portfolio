## Confidentiality

All portfolio dashboard values, sample site names, management commentary, tables and visual previews are synthetic.
No original employer dashboard screenshot, company dataset, customer data, site data or internal KPI value is included.

## How to publish

### GitHub Pages
1. Create a new GitHub repository.
2. Upload all files from this folder to the repository root.
3. In GitHub: Settings → Pages.
4. Select `Deploy from a branch`.
5. Select the `main` branch and `/root`.
6. Save.

### Netlify
Drag the complete folder into Netlify's deployment interface.

### Vercel
Import the GitHub repository as a static project.

## Final optional personalization

The website is usable as-is. For the strongest public version, add:
- Your exact LinkedIn profile URL.
- A GitHub profile only if you plan to publish clean/synthetic analytics projects.
- A professional headshot only if you want one; the current design intentionally works without a photo.
- Custom domain such as `numairkhan.com` or similar if available.
